# 锐音场微信小程序 84 屏设计规格

## 1. 目标与范围

在 `ip_actor_wechat` 中实现《锐音场小程序完整界面蓝图 84 屏 v4》定义的 S01-S84，并遵循《锐音场微信小程序 · 研发方案》的业务边界。

交付口径：

- 84 个界面全部存在、可导航、可操作和可恢复。
- 当前 FastAPI 已提供的能力使用真实接口。
- 尚无后端接口的规划能力使用统一示例数据服务和本地状态机实现，不伪装成真实数据。
- 页面明确区分事实、假设、建议、示例与人工确认。
- 缺失数据不得按 0 处理；越权、网络失败、旧版本和处理中状态有独立页面。

## 2. 技术架构

实现采用 Taro + React + TypeScript，目标平台为微信小程序。视觉和交互保持微信原生体验，与蓝图一致。

目录边界：

- `src/pages`: 四个主入口及高频一级页面。
- `src/package-project`: 项目创建、测算、证据、风险、决策和复盘分包。
- `src/package-agent`: Agent、任务、变化提醒和授权分包。
- `src/package-account`: 登录、空间、团队、设置、权限与通用异常分包。
- `src/components`: 导航栏、底部 Tab、指标、状态标签、列表项、图表、空状态和确认面板。
- `src/services`: HTTP 请求、认证、租户上下文、示例数据和错误归一化。
- `src/store`: 会话、当前空间、当前项目、草稿和界面状态。
- `src/domain`: 财务展示模型、状态映射、权限和版本辅助函数。

## 4. 导航设计

底部固定四个主 Tab：

- 发现：S04/S05
- 项目：S10 或 S73
- Agent：S52
- 我的：S67

二级页面使用栈式导航。创建流程、决策确认、任务提交等连续流程保留返回路径和草稿。S75-S81 作为可复用状态页，由业务页面携带来源页面和恢复参数进入。

## 5. 数据策略

### 真实接口

- 微信登录、客户空间列表和切换。
- 项目列表、创建、详情和版本。
- 财务测算与保本计算。
- 事实、证据、假设、门禁和风险。
- 决策、任务、Agent 对话、案例搜索和报告分享。
- 艺人、演出和预约。

统一解析 `{"code": 0, "data": ..., "message": "..."}`。

### 示例数据

以下能力在现有后端未完整提供，首版由 `mock-service` 返回蓝图示例并标记 `isExample`：

- 机会发现和复杂组合推荐。
- OCR 抽取、冲突自动检测。
- Agent 计划自动派发、阻塞流转和消息中心。
- 巡演路线、实时售票、结算复盘。
- 团队邀请、通知偏好和个人信息申请。

示例数据不可写成“已核验事实”，页面持续展示数据性质。

## 6. 关键交互

- 创建项目为五步表单，按客户空间保存草稿。
- 财务页统一展示三情景、保本线、敏感性和资金缺口。
- 任何关键输入修改都提示将生成新版本。
- 决策动作必须展示对象、版本、条件和后果，并二次确认。
- 上传资料后进入候选事实状态，不直接成为正式事实。
- 任务提交后进入待核验，不直接完成。
- 页面加载、空数据、失败、权限不足和登录过期均保留用户上下文。

## 7. 视觉规范

- 使用蓝图的白底、深墨文字、蓝色主操作、橙红风险提示和浅灰分区。
- 卡片圆角控制在 8px 内，不嵌套卡片。
- 首页和结果页优先展示结论、关键数字和下一步动作。
- 图表使用稳定尺寸，避免加载后布局跳动。
- 所有按钮、标签和长文本在 320-430px 宽度内无横向溢出。
- 页面不出现 `demo` 或 `MVP` 文案。

## 8. 错误与安全

- 请求层统一处理超时、业务错误、401、403 和网络断开。
- 401 进入 S81；403 进入 S77；上下文失败进入 S76。
- 重试前先查询提交状态，避免重复创建、重复确认或重复提交。
- Token、服务密钥和真实对象存储签名不写入客户端源码。
- 客户空间切换后清理项目级缓存和草稿引用。

## 9. 测试与验收

- 每个新增领域函数必须有单元测试。
- 核心流程覆盖：登录、空间选择、创建五步、财务测算、证据核验、门禁确认、负责人决策、任务提交、报告分享。
- 页面注册测试验证 S01-S84 均有路由映射。
- 导航测试验证四个主 Tab 和二级返回路径。
- 状态测试覆盖 S73-S81。
- 构建、类型检查、单元测试和预览均通过。
- 84 屏按蓝图逐屏检查标题、关键指标、主操作和数据标记。

## 10. 实施顺序

1. 初始化 Taro 工程、主题、请求层、状态层和测试框架。
2. 完成四个主 Tab、登录、空间与通用状态。
3. 完成项目创建和财务闭环。
4. 完成证据、风险、门禁、决策和报告。
5. 完成 Agent、任务、巡演、复盘和账户协作。
6. 逐屏预览、接口联调、测试和响应式验收。
